# Wii Modern Media Player — اصلاح نهایی DVD و کنترل‌ها

این نسخه نوار جدیدی روی تصویر اضافه نمی‌کند؛ نوار اصلی WiiMC همان نوار کنترل ویدئو باقی می‌ماند.

اصلاحات:
- A با اشاره‌گر در DVD = کلیک DVDNav؛ بدون اشاره‌گر = Select.
- 2/Y + A = Select و 2/Y + D-pad = حرکت در منوی DVD.
- B در منوی DVD = برگشت به منوی DVD؛ B + جهت رفتار Zoom/Resize اصلی WiiMC را نگه می‌دارد.
- A در پخش عادی وقتی اشاره‌گر روی GUI است توسط GUI اصلی WiiMC مصرف می‌شود و فقط بدون اشاره‌گر Pause می‌کند.
- فایل‌های کوتاه VOB/IFO داخل ساختار DVD به VIDEO_TS.IFO نرمال می‌شوند تا یک VOB منوی کوتاه به‌عنوان ویدئوی مستقل تکرار نشود.
- `apply_wiimc_patch.py` تنها نقطه اعمال پچ است و `build_upstream.sh` دقیقاً همان پچ را قبل از کامپایل اجرا می‌کند.

## تست
این بسته قبل از تحویل از نظر ساختار Python/Shell و وجود anchorهای پچ بررسی شده است. کامپایل PowerPC و تست فیزیکی Wii فقط در GitHub Actions/خود Wii قابل تأیید است.
